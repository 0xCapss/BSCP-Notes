# Index - Préparation BSCP

Carte de contenu de ce vault. La BSCP (Burp Suite Certified Practitioner) porte
sur la Web Security Academy de PortSwigger. Objectif : maîtriser chaque famille
de vulnérabilité et savoir l'exploiter avec Burp, du repérage au rapport.

## Comment utiliser ce vault
- Une note par vulnérabilité, avec un squelette commun à remplir toi-même
  (détection, exploitation, prévention, tes notes). Le savoir, tu l'écris.
- Mets à jour le champ `statut` de chaque note : `à faire`, `en cours`, `maîtrisé`.
- Coche les labs faits dans chaque note, et suis l'avancement dans [[00-Suivi]].
- Avant l'examen, relis [[00-Methodologie-BSCP]].
